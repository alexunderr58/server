\doxysubsection{Подробное описание}
Класс для управления базой данных клиентов 

Реализует хранение пар логин-\/хэш\+\_\+пароля в памяти с возможностью сохранения в файл и загрузки из него. Потокобезопасен за счет использования мьютекса.
